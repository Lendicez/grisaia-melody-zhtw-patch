# 灰色的旋律 繁體中文化補丁

Steam 版《The Melody of Grisaia》（グリザイアの旋律，**日文版**）的繁體中文化補丁。
一個安裝程式即可把遊戲改成繁體中文，並順帶修正中文系統上的存檔問題、強化視窗模式的操作。

## 補丁內容

### 繁體中文化
- **劇本**：全部對白與旁白（1,350 句）、角色名字欄。
- **介面圖片**：標題選單、環境設定各頁、存讀檔、CG／BGM／影片／場景鑑賞、對話框、跳轉中、開機注意畫面等含文字的圖片，重繪為繁中。
- **系統文字**：章節名稱、確認對話框、遊戲標題列，以及 System 按鈕開啟的「遊戲環境設定」「系統環境設定」視窗。
- **字型**：對話使用「微軟正黑體」；刪節號、破折號改用「細明體」繪製，避免斷開。
- 專有名詞沿用系列既有中文譯名（灰色的果實／迷宮／樂園、風見雄二、日下部麻子、JB 等），新角色依中文圈通行譯名。

### 存檔修正（中文系統必備）
原版的存檔資料夾名稱是日文（`%APPDATA%\フロントウイング\グリザイアの迷宮 ～グリザイアの旋律～`），在繁中 Windows 上無法建立，
導致**無法存檔**，按「結束遊戲」時也會跳出錯誤訊息而看似卡住。補丁會讓遊戲以正確的日文名稱存取這個資料夾，
與日文系統、Locale Emulator 及 Steam 雲端存檔的位置一致。

### 視窗模式強化
啟動時選「視窗模式」後：

| 操作 | 效果 |
|---|---|
| 拖拉視窗邊框 | 自由調整大小，固定 16:9 比例 |
| 最大化按鈕 | 畫面等比放大，多出的部分以黑邊補齊（黑邊上點擊無作用） |
| `Alt+Enter`／`F11`／設定頁「切換全螢幕」 | 改為**無邊框全螢幕**（仍是視窗，不切換桌面解析度），再按一次回到原本的視窗大小與位置 |
| 系統環境設定 →「顯示 1」→「遊戲視窗大小」 | 原版的視窗尺寸切換照常可用，切換後以所選尺寸執行 |

縮放、最大化與全螢幕時，滑鼠點擊位置會自動對應，可正常操作。

## 安裝

1. 在 Steam 確認遊戲語言為**日文**（遊戲內容 → 語言），等更新完成。
2. 關閉遊戲，執行 `GrisaiaMelody-zhTW-Patch-1.0.0.exe`。程式會自動找到 Steam 遊戲資料夾（也可手動選擇），按「安裝」。
3. 從 Steam 啟動遊戲即可。

- 安裝前會核對原版檔案；原檔備份在遊戲資料夾的 `_zhTW_backup\`，隨時可用同一個程式「解除安裝」還原。
- 不會修改存檔。
- Steam「驗證遊戲檔案完整性」或遊戲更新會還原成原版，重新執行安裝程式即可。

> 安裝程式沒有數位簽章，且會在遊戲資料夾放置 `version.dll`（顯示與修正功能所需），少數防毒軟體或 Windows SmartScreen 可能提示風險。
> 請核對發行頁上的 SHA-256 確認檔案未被竄改。

## 設定（`zhtw.ini`，位於遊戲資料夾）

| 區段 | 項目 | 預設 | 說明 |
|---|---|---|---|
| `[window]` | `enable` | `1` | 視窗模式強化；設 `0` 恢復原版行為 |
| `[fs]` | `enable` | `1` | 存檔資料夾修正；設 `0` 關閉 |
| `[font]` | `face` | `Microsoft JhengHei` | 對話字型 |
| `[log]` | `enable` | `0` | 除錯記錄（`zhtw_hook.log`） |

## 已知限制
- 僅支援 Steam 日文版（AppID 464500）；遊戲更新後若檔案變動，需等待補丁更新。
- 遊戲本身的「全螢幕模式」已改為無邊框全螢幕，不再切換顯示器解析度。

## 開發者資訊

| 路徑 | 用途 |
|---|---|
| `tools/` | CatSystem2 解包／重組（`cs2int.py`）、劇本（`cst.py`）、圖片（`hg3.py`）、組裝（`build_patch.py`）、介面重繪（`ui_*.py`）、安裝程式編譯與自我測試 |
| `hook/` | `version.dll` 原始碼：文字顯示（`zhtw_hook.c`）、存檔路徑（`zhtw_fs.c`）、視窗強化（`zhtw_window.c`）、設定對話框（`zhtw_dlg.c`）、診斷（`zhtw_diag.c`、`zhtw_wndprobe.c`）；`third_party/minhook`（BSD-2） |
| `installer/` | C# 單一 EXE 安裝程式（.NET Framework 4） |
| `translation/` | 繁中譯文（只含 id 與中文）、專有名詞表、翻譯規範與驗證腳本 |
| `ui/specs/` | 介面圖片重繪設定（只含中文與座標） |
| `lab/` | Windows 實機自動測試 |
| `docs/HANDOFF.md` | 技術紀錄與完整流程 |

技術重點：引擎為 2016 年 Shift-JIS 版 CatSystem2，檔案內以 CP932 加「借位碼」存放繁中字，顯示時由 `version.dll` 全程轉為 Unicode 繪製。
本庫只收原始碼、自製程式與繁中譯文，不收遊戲檔、日文原文或截圖。
