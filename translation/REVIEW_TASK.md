# 任務：《灰色的旋律》繁中譯稿審稿（第二位譯者交叉審核）

資料（本資料夾）：`in-NNN.json`（日文原文、說話者）、`out-NNN.json`（第一輪譯文）、`glossary.zh-TW.json`、`TASK.md`（翻譯規範）、`NOTES.md`。
你是審稿人，不是重譯：只修有問題的句子，不要為了個人偏好改寫通順正確的譯文。

## 要找的問題（依重要性）
1. 誤譯：意思錯、主詞／受詞搞錯、否定與肯定相反、漏譯整個子句、把反話當真話。
2. 角色語氣：雄二（冷靜、毒舌、冷面笑話）、瑪麗安（任性大小姐、對雄二用「風見」）、伊莎貝拉（禮貌幹練）、
   諾波亞一夥（粗魯黑道）、JB（電話中，傲嬌）。同一角色前後的自稱、稱呼、口癖要一致。
3. 專有名詞與用語不一致（依 glossary；表上沒有的同一名詞全書要統一）。
4. 台灣用語：避免中國用語（視頻、質量、搞定、靠譜、牛、給力、打車……）、生硬翻譯腔。
5. 標點：「」『』……──～！？全形一致；原文「」包住的句子譯文也要。
6. `NOTES.md` 列出的 3 句安全改寫：維持非性化的處理，不要改回原意；可只潤飾語句通順。

## 產出（本資料夾，UTF-8；禁止用 PowerShell 重導向寫中文，請用檔案編輯工具或 `python -X utf8` 腳本）
- `fix-NNN.json`：每批一個（沒有要改的批次可不建立），格式 `[{"id": "...", "zh": "修正後全文", "reason": "簡短理由"}]`，
  只列要改的句子。每個 fix 檔執行 `python validate.py fix-NNN.json` 必須通過。
- `REVIEW.md`：整體評估、問題分類統計、最重要的 20 個修正例子（原譯 → 新譯 → 理由）、對 glossary 的建議（若有）。
- 完成後建立 `REVIEW-DONE.txt`（一行摘要：各類修正數）。

## 不要做的事
- 不要修改 in-*.json、out-*.json、validate.py、glossary.zh-TW.json、TASK.md。
- 不要上網、不要安裝套件、不要動本資料夾以外的檔案。
