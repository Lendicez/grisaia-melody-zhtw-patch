# 任務：《灰色的旋律》（グリザイアの旋律）劇本 日文 → 繁體中文（台灣）

本資料夾有 `in-000.json` … `in-011.json`（每批約 115 則），每則：
`{"id": "001:0010", "speaker": "雄二" 或 null, "ja": "日文原文", "ja_len": 字數}`。
id 依劇本順序排列，前後則就是上下文；`speaker` 為 null 表示雄二的內心獨白或旁白（本作以雄二第一人稱「俺」敘事）。

請為**每一批**建立 `out-NNN.json`（與 in 同號），格式：`[{"id": "001:0010", "zh": "繁中譯文"}, ...]`，
列數、id、順序與 in 檔完全相同。每做完一批立刻執行 `python validate.py out-NNN.json`，通過才做下一批；
有錯就修到通過。全部完成後執行 `python validate.py out-*.json`（PowerShell：`python validate.py (Get-ChildItem out-*.json)`），
看到 `ALL OK` 後建立 `DONE.txt`（一行摘要）。

## 檔案編碼（重要）
禁止用 `echo`、`Set-Content`、`Out-File`、`>` 重導向或命令列參數寫中文（會變成 `?`）。
請用檔案編輯工具（apply_patch／直接寫檔）建立 out 檔，內容 UTF-8。若用腳本，中文寫在 UTF-8 的 .py 檔裡、以 `python -X utf8` 執行。

伊莎貝拉是瑪麗安身邊的女性（敬語、幹練）；諾波亞一夥是黑道、粗口。

## 風格
- 台灣繁體中文、自然口語，像台灣代理的 Galgame／輕小說；保留原文語氣、性格與笑點，避免逐字直譯與中國用語（例：「視頻、質量、搞定了沒、牛」等）。
- 標點全形：「」『』（）！？……──～。原文的「」『』括號必須照樣保留在譯文開頭結尾（validate 會檢查）。
- 刪節號用「……」；破折號用「──」；長音「ー」依語氣用「～」或疊字。
- 擬聲／喘息（「ぐわぁぁ」「ッッ」）譯成自然中文擬聲（「嗚哇啊啊」「唔……！」）。
- 不要加譯註、不要加說明、不要留日文假名。
- 不可用半形 `[ ] \ @ # { } < > | `` ` ``（遊戲腳本控制字元）。英數字可用半形（JB、CIA、M24-SWS）。
- **長度**：一則訊息要放進遊戲訊息框，validate 以「全形字數」檢查，上限 = min(90, max(原文字數+8, 原文字數×1.3))。中文通常比日文短，放不下就精簡意譯。
