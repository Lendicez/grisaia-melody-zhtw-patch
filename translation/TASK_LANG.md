# 任務：《灰色的旋律》系統字串表（language.txt）日文 → 繁體中文（台灣）

`lang-in-NNN.json` 每筆 `{"id": "0000-0042", "ja": "日文原文", "en": "官方英文版譯文（參考用，可能是 $nr$）"}`。
這些是 Windows 對話框、確認訊息、環境設定程式（畫面、音效、文字速度、快捷鍵、提示說明）與選單的文字。
請為每批建立 `lang-out-NNN.json`：`[{"id": "...", "zh": "繁中"}]`（筆數、順序與 lang-in 相同），
每批執行 `python lang_validate.py lang-out-NNN.json` 通過再做下一批；全部完成後 `python lang_validate.py lang-out-*.json` 看到 ALL OK，建立 `LANG-DONE.txt`。

## 規則
- 以**日文原文**為準翻譯，英文只作理解參考。台灣 Windows 軟體慣用語（例：確定、取消、是、否、全螢幕、視窗模式、音量、語音、文字速度、自動模式、快轉、存檔、讀檔、設定、回想、說明）。
- 格式符號原樣保留且順序不變：`%s` `%d` `%02d` `%c` `%%` `\n`。
- 快速鍵 `(&X)` 等要保留：`ゲームの終了(&X)` → `結束遊戲(&X)`。
- 長度：對話框寬度固定，譯文盡量不比日文長（validate 上限 = 日文字數×1.3＋2，以全形字計）。
- 作品標題：グリザイアの旋律 → 灰色的旋律、グリザイアの迷宮 → 灰色的迷宮。
- 開發用／除錯用項目（デバッグ、シーンリスト、メッセージリスト等）也照譯。
- 標點全形；不要留日文假名；只用繁體常用字（validate 會檢查 cp950）。
- 檔案編碼 UTF-8；禁止用 PowerShell 重導向／echo 寫中文，請用檔案編輯工具或 `python -X utf8` 腳本。
- 不要改 lang-in、lang_validate.py；不要上網、不要安裝套件、不要動本資料夾以外的檔案。
